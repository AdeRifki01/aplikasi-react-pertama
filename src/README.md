# Aplikasi React Pertama - Modul 1.2

aplikasi web interaktif modular yang dibangun menggunakan React dan Vite.

## Fitur Aplikasi
- Tombol Counter interaktif berbasis state.
- Kolom input nama dengan sapaan real-time.
- Struktur kode modular terpisah di folder components

## Cara Menjalakan Proyek
- Buka terminal di folder proyek.
- Jalankan perintah : 'npm run dev'
- Akses alamat dibrowser : 'http://localhost:5173'
